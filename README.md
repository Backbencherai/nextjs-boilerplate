# A×D — Our Growth Universe

A private, explorable 3D world where Adarsh and Dewanshi level up in real life.

## Deploy (pick one)

**Netlify, no tools needed:** unzip `AxD-netlify-drop.zip`, go to https://app.netlify.com/drop and drag the unzipped folder onto the page. It's live in about 10 seconds.

**Netlify or Vercel from GitHub:** import this repo. Both hosts read the included `netlify.toml` / `vercel.json` (build `npm run build`, output `out`).

**Vercel CLI:** run `npm i -g vercel`, then `vercel deploy --prod` inside the unzipped `AxD-netlify-drop` folder.

**Locally:** run `npm install && npm run dev`, or `npm run build` and then serve `out/` with any static server.

The build is fully static (`output: "export"`), so it runs on any static host.

## Multiplayer: works anywhere, no setup
Both players open the site, pick who they are and enter the same **join code** (pre-filled: `LOVE`). That's it: you're in one live universe from anywhere in the world.

- **Live:** you see each other walk around the world (and drive). Logs, cheers, bottle notes, medals and builds show up on the other phone within seconds. There's an online indicator ("● both online").
- **History:** every activity is kept on the relay. A phone that was offline, or a brand-new phone, catches up when it joins with the code. Each phone also keeps its own copy and re-shares it, so nothing is lost.
- **Private:** everything is encrypted (AES-GCM) with a key derived from your join code. The relays only see scrambled data under a random-looking topic.
- **How:** two free public MQTT-over-WebSocket relays (EMQX and HiveMQ) are used at once, so if one is down the other carries on. The relay list is in `sync-config.json`; the code is in `lib/sync/relay.ts`.

**Optional: your own Supabase.** For a database you control, run `supabase/schema.sql` in a free Supabase project. Then put `supabaseUrl` and `supabaseAnonKey` in `sync-config.json`. When those are set, the app uses Supabase instead of the relays.

## Install it like an app
Open the site on your phone:
- **Android / Chrome:** tap the "Install the app" card on Home, or use Chrome's menu and choose Install.
- **iPhone / Safari:** tap Share, then Add to Home Screen.

It opens full-screen with its own icon, and works offline (the service worker is `public/sw.js`).

## Island projects (the game loop)
Bridges start missing and appear plank by plank as you make real progress:
- Adarsh's Bridge: Adarsh earns 150 XP
- Dewanshi's Bridge: Dewanshi earns 150 XP
- Mind Bridge: 2 hours of study combined
- Body Bridge: 90 minutes of workouts combined

Later projects:
- Cozy House: each player reaches level 4
- Two-Storey House: each player reaches level 7
- Island Car: 6 medals between you. It's drivable at twice the speed.
- Wishing Fountain: you're both active on 5 days
- Fireworks: 12 medals between you

Once the bridges are built you can walk to each other's island and visit each other's museum. Open 🔨 in the world, or see Home or Quests, for progress. The rules live in `lib/game/builds.ts`.

## Characters
Adarsh and Dewanshi are rigged and animated. They're based on **KayKit Adventurers** by Kay Lousberg (CC0, www.kaylousberg.com), re-dressed in Blender by `blender/make_people.py`: fantasy props removed, outfits recoloured, and an everyday set of animations kept (idle, walk, run, cheer, sit, and more).

## 3D assets (Blender)
`public/models/axd.glb` is generated by `blender/make_assets.py` using Blender 5.2's Python module. It contains the rigged characters (parts are pivoted at the joints), sculpted islands, metaball trees, bushes and clouds, rocks, and the crowd figures. To rebuild it:
```bash
pip install bpy
python blender/make_assets.py -- public/models/axd.glb
```
If the GLB can't load, every model falls back to its procedural version.

## What's inside
- Opening: a loader with real progress and Pip the mascot, a 5-chapter 3D story, and interactive onboarding.
- 3D world (`/world`): five floating islands, playable characters, partner shown live, daily XP coins, activity locations (Library, Spring, Forge, Garden, Well, Bonfire, Quest Board, Hall of Fame, Observatory, Bottle Dock), joystick or tap-to-walk, fast-travel map.
- Personal islands grow from real data: trees come from your level, flowers from your streak, the crystal from study hours, the cairn from workout hours.
- Quick log from anywhere: study, workout and meditation timers (they survive reloads), meals, water, sleep, mood, steps, and past sessions.
- XP and levels, 37 medals (27 solo and 10 shared), PNG certificates, Hall of Fame records, leaderboards, daily, weekly and together quests, analytics, and 3D museums (`/museum/adarsh|devanshi|together`).
- Six hidden secrets (Konami code, the sun, the duck, the glowcap, the logo, Pip).

## Design
The art direction follows dontlookup.app: off-white paper (`#f4f3ef`), near-black ink (`#14140f`), chunky hand-lettered caps, 2.5px outlines, hard offset shadows and wobbly card corners. Color is used sparingly: blue for Adarsh, red for Dewanshi, yellow for rewards.

The 3D look comes from `components/three/Ink.tsx`. It gives every mesh 3-step toon shading, washes its color toward paper and adds an inverted-hull ink outline. Meshes marked `userData.keep` keep their color.

Fonts are Luckiest Guy and Nunito from Google Fonts, not the reference site's licensed FGD font. All models and code are original. Nothing is copied from the reference sites.
